An original 3D Roblox brainrot game built for the [make.fun "Make the best AI Roblox brainrot game" bounty](https://make.fun/bounty/roblox-brainrot-01): collect absurd meme characters that earn cash every second, stack them on your base, climb the rarity and mutation ladder, and guard them against the sweep while you dash home with each new catch.

Built with Rojo: the Luau sources live under `src/`, `rojo build default.project.json --output game.rbxl` writes the place file, and `node main.ts` hands the entry in.
